\section{Итоги}

\begin{frame}
    \frametitle{Основные результаты}
    \begin{enumerate}
        \item Сформулирована постановка многоклассовой классификации почты
              с~персонализированными классами и~отказом \texttt{other}.
        \item Разработана локальная архитектура: синхронизация, нормализация,
              эмбеддинги, кластеризация, ручная проверка, прототипы
              и~применение классификатора.
        \item Реализован прототип на~Python: PostgreSQL хранит состояние,
              \texttt{BAAI/bge-m3} строит эмбеддинги, HDBSCAN группирует
              письма, интерфейс ручной разметки принимает пользовательские
              метки.
        \item Для выполнения цели проведены синхронизация и~нормализация
              писем, построение эмбеддингов, кластеризация, ручная проверка,
              обучение прототипов и~оценка классификатора.
        \item Эксперимент на~7107 письмах дал значения macro-F1~0{,}835,
              weighted-F1~0{,}847 и~покрытие~0{,}996.
    \end{enumerate}
\end{frame}
