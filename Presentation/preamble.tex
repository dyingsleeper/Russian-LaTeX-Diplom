\section{Постановка задачи}

\begin{frame}
    \frametitle{Проблема и ограничения}
    \begin{itemize}
        \item Почтовый архив содержит рабочую переписку, уведомления, документы
              и~разовые сообщения на~русском и~английском языках.
        \item Ручная сортировка требует постоянных затрат, а~правила
              по~отправителю или~теме быстро устаревают.
        \item Готовые клиенты обычно выделяют общие категории
              <<важное~/ неважное>>, но~не~формируют персональные классы
              пользователя.
        \item Текст писем содержит персональные и~рабочие данные, поэтому
              обработка должна выполняться локально.
    \end{itemize}
\end{frame}

\begin{frame}
    \frametitle{Цель и задачи работы}
    \textbf{Цель:} разработать локальную интеллектуальную систему классификации
    текстовых документов на~примере электронной почты.

    \medskip
    \begin{enumerate}
        \item Проанализировать методы классификации текстов и~организации почты.
        \item Сформулировать постановку с~персонализированными классами,
              порогом уверенности и~отказом от~классификации.
        \item Спроектировать локальную архитектуру обработки, кластеризации
              и~классификации писем.
        \item Реализовать прототип и~экспериментально оценить качество.
    \end{enumerate}
\end{frame}
