{\actuality} Текстовые документы остаются основным средством хранения
и~передачи информации в~деловой, учебной и~научной деятельности. Их объём
в~личных и~корпоративных хранилищах растёт быстрее, чем поддаётся ручному
упорядочению, поэтому актуальна автоматическая классификация документов
по~тематическим или функциональным категориям конкретного пользователя.

Электронная почта является характерным примером такой задачи. Почтовый ящик
профессионального пользователя объединяет переписку, уведомления, документы,
задачи и~технические сообщения объёмом до~нескольких сотен входящих писем
в~день \autocite{Singh2023EmFORE}. Ручная сортировка такой корреспонденции
требует постоянных временных затрат, а~правила по~отправителю или теме быстро
устаревают при смене проектов, контрагентов и~форматов уведомлений.

Готовые почтовые клиенты предлагают механизмы приоритизации входящих сообщений,
но чаще ориентируются на~общие категории вроде «важное~/ неважное» и~не
отражают индивидуальную структуру архива. При этом письма содержат персональные
данные, коммерческую информацию и~фрагменты внутренних документов, поэтому
передача текста во~внешние сервисы не~всегда допустима. Это делает востребованной
локальную систему, которая формирует персонализированные классы по~исторической
почте и~классифицирует новые сообщения без выхода текста за~контролируемый
контур.

{\progress} Задача автоматической классификации текстов исследуется в~рамках
обработки естественного языка и~машинного обучения: от~статистического
рубрицирования документов до~современных векторных представлений. Применительно
к~электронной почте известны подходы TaskTracer, где предсказываются проекты
пользователя с~помощью наивных байесовских и~линейных классификаторов
\autocite{Keiser2009TaskTracer}, и~EmFORE, где правила распределения писем
по~папкам обучаются онлайн с~учётом дрейфа пользовательских категорий
\autocite{Singh2023EmFORE}. Эти работы показывают необходимость учитывать
персональные классы, новые типы сообщений, низкоуверенные решения и~обратную
связь пользователя.

В~данной работе рассматривается локальный процесс обработки: нормализация писем,
построение многоязычных (multilingual) эмбеддингов, кластеризация исторической почты для
начального формирования классов и~обучение классификатора на~полученной
разметке. Низкоуверенные сообщения выделяются в~категорию \texttt{other} как
отказ от~автоматической классификации и~материал для последующей проверки.

{\aim} работы является разработка интеллектуальной системы классификации
текстовых документов на~примере электронной почты, способной работать локально,
поддерживать персонализированные классы, формировать их по~исторической выборке
и~оценивать качество принимаемых решений.

Для достижения поставленной цели необходимо решить следующие {\tasks}:
\begin{enumerate}[beginpenalty=10000]
  \item проанализировать подходы к~классификации текстов
        и~автоматической организации электронной почты;
  \item сформулировать постановку задачи с~персонализированными классами,
        порогом уверенности и~отказом от~классификации;
  \item разработать локальную архитектуру обработки, кластеризации
        и~классификации писем;
  \item реализовать прототип системы и~провести экспериментальную оценку
        качества её работы.
\end{enumerate}

\textbf{Объект исследования.} Процесс автоматической многоклассовой
классификации текстовых документов с~учётом персонализированных пользовательских
классов.

\textbf{Предмет исследования.} Методы и~алгоритмы построения локальной системы
классификации электронной почты, включая нормализацию текста, векторное
представление сообщений, кластеризацию исторической выборки, обучение
классификатора и~обработку отказов от~классификации.

{\methods} В~работе применяются методы системного анализа, обработки
естественного языка и~машинного обучения: построение векторных представлений,
кластеризация на~основе плотности, обучение классификаторов и~оценка качества
моделей. Для экспериментов используются accuracy, macro-F1, взвешенный F1,
precision, recall, показатели кластеризации, покрытие и~доля отказов
в~категорию \texttt{other}. Воспроизводимость обеспечивается фиксированной
конфигурацией, сохранением артефактов моделей и~версионированием данных.

{\novelty}
\begin{enumerate}[beginpenalty=10000]
  \item Предложен локальный процесс классификации электронной почты, объединяющий
        нормализацию MIME-сообщений, многоязычные эмбеддинги, кластеризацию
        исторической выборки и~классификацию новых сообщений без передачи текста
        во~внешние сервисы.
  \item Разработан способ начального формирования пользовательских классов через
        кластеризацию исторической почты с~выделением выбросов и~последующей
        ручной проверкой кандидатов.
  \item Предложена схема принятия решений с~явным отказом от~классификации
        (\texttt{other}) и~критериями активации модели (quality gates) по~метрикам
        качества и~операционным характеристикам.
\end{enumerate}

{\influence} работы состоит в~создании прототипа локальной системы
классификации электронной почты для окружений, где требуется сохранить
приватность почтовых данных и~получить персонализированную автоматическую
классификацию. Прототип выполняет синхронизацию по~IMAP только на~чтение, нормализацию
писем, кластеризацию, обучение модели, инференс и~сохранение предсказаний без
изменения состояния почтового ящика.

{\defpositions}
\begin{enumerate}[beginpenalty=10000]
  \item Локальные многоязычные эмбеддинги применимы для построения единого
        признакового пространства русско-английских почтовых сообщений
        и~могут использоваться как основа кластеризации и~классификации.
  \item Кластеризация исторической почтовой выборки позволяет формировать
        кандидаты на~персонализированные классы без предварительного задания
        фиксированного числа категорий и~с~явным выделением выбросов.
  \item Порог уверенности, категория \texttt{other} и~критерии активации снижают риск
        ошибочной автоматической классификации и~создают основу для управляемой
        обратной связи.
\end{enumerate}

{\reliability} результатов обеспечивается использованием открытых методов
машинного обучения и~обработки текста, воспроизводимой конфигурацией
экспериментов, сохранением артефактов моделей и~данных и~сравнением с~базовыми
подходами.
