# Компоновка строки научного руководителя

## Цель

Разделить строку научного руководителя в `Dissertation/task.tex` на две независимые области. Левая область содержит подпись, правая содержит степень, должность и сокращённое ФИО.

## Компоновка

- Левая область имеет ширину `8.5cm`. В ней остаются надпись «Руководитель», линия длиной `5cm` и подпись «(подпись)» под линией.
- Правая область занимает оставшуюся ширину строки. Текст переносится только внутри этой области.
- Обе области выравниваются по верхней строке.
- Высота правого текста не меняет положение подписи в левой области.

Для разметки используются две соседние `minipage`. Такой вариант не связывает строки двух областей общей высотой таблицы.

## Проверка

Сборка `make dissertation` должна завершиться без ошибок. На четвёртой странице PDF степень, должность и ФИО остаются справа, а «(подпись)» располагается под линией и не пересекается с правым текстом.
