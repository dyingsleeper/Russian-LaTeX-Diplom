Глава 3 показывает, **как** спроектированная в главе 2 система `diplom-ai`
реализована, и **насколько хорошо** она работает на реальной выборке. Она
наследует то, что глава 2 явно отложила: экспериментальные результаты, подбор
параметров и оценку качества (см. выводы главы 2, `sec:ch2/concl`). Глава
закрывает задачи листа задания:
реализацию конвейера и оценку качества по метрикам классификации, покрытию и
доле отказов (`other`).

Реальный код проекта расположен в `/home/dyingsleeper/PycharmProjects/diplom2.0`
(`src/diplom_ai/`). Листинги и числа берутся оттуда; на этапе каркаса — заглушки.

## Ключевые решения (согласовано с автором)

1. **Роль главы.** «Реализация и экспериментальное исследование системы»:
   реализация (с листингами) + эксперименты. Не «только эксперименты» и не
   «только реализация».
2. **Листинги.** Компактные фрагменты ключевого кода (≈10–40 строк) — в тексте
   главы с разбором; полные/длинные модули — в приложение через
   `\lstinputlisting`. Пакет `listings` уже настроен (`Dissertation/userpackages.tex`,
   стиль и подпись «Листинг» в `Dissertation/userstyles.tex`); пример
   `\lstinputlisting` уже есть в `Dissertation/appendix.tex`.
3. **Данные.** Реальный почтовый ящик автора (ru+en), синхронизированный по IMAP.
   В тексте — обезличенное описание (объём выборки, доли языков, период,
   результаты фильтра качества), без приватного содержимого; примеры писем
   анонимизированы.
4. **Блоки результатов (выбраны автором):**
   - (1) Кластеризация: метрики (число кластеров, доля шума, DBCV, силуэт,
     индекс Дэвиса–Боулдина) + 2D-проекция + таблица топ-терминов TF-IDF.
   - (2) Подбор параметров (Optuna): история оптимизации, лучшие параметры,
     важность + сравнение HDBSCAN+тюнер vs дефолтные параметры vs KMeans.
   - (3) Классификатор: accuracy, macro-F1, weighted-F1, покрытие, доля `other`,
     поклассовые precision/recall/F1, матрица ошибок, развёртка метрик по порогу
     уверенности τ.
   - **Не включаем:** качественный анализ примеров, производительность/ресурсы,
     демонстрацию цикла переобучения при дрейфе.
5. **Структура — по этапам конвейера (вариант B).** Для каждого этапа
   реализация (листинг) и его результат идут вместе. Слабость варианта —
   «размазанная» оценка качества — компенсируется финальным сводным разделом
   «достигнуто против критериев успеха» (`subsec:ch1/dev/success`).
6. **Рисунки-плейсхолдеры.** На месте каждого рисунка — рамка-заглушка
   фиксированного размера с полной подписью и меткой; позже заменяется на
   `\includegraphics`. Места под рисунки сохраняются уже сейчас.
7. **Числа-плейсхолдеры.** Через макрос `\fixme{...}` (как в `common/data.tex`,
   рендерится красным до замены).

## Структура главы (9 разделов)

### Вводные разделы

**3.1 Среда реализации и организация кода** (`\label{sec:ch3/impl}`)
Стек: Python 3.12; `sentence-transformers`, `hdbscan`, `optuna`, `scikit-learn`,
`torch`, `psycopg`, `argilla`. Структура `src/diplom_ai` по слоям (пакеты из
главы 2). Инструменты качества: `ruff`, `mypy`, `pytest`. Запуск инфраструктуры
(PostgreSQL + Argilla) через Docker Compose. Один листинг (Л3.1) — цикл дренажа
очереди задач. Таблица модулей→назначение либо ссылка на таблицу главы 2 (без
дублирования архитектуры).

**3.2 Данные и экспериментальная установка** (`\label{sec:ch3/setup}`)
Обезличенное описание корпуса: объём, доли ru/en, период, результаты фильтра
качества (`ok/empty/too_short`). Аппаратная конфигурация и версии (модель
`BAAI/bge-m3` и её версия, сиды воспроизводимости). Краткое напоминание
определений метрик из главы 1 со ссылками (DBCV, силуэт, индекс
Дэвиса–Боулдина; accuracy/macro-F1/weighted-F1/покрытие/доля `other`). Все числа
— `\fixme{...}`.

### Стержень — этапы конвейера (реализация + результат)

**3.3 Синхронизация и нормализация** (`\label{sec:ch3/norm}`)
Листинг Л3.2 (`email/normalization.py`): токенизация
`LINK/EMAIL/DATE/TIME/NUM`, удаление цитат/подписей/футеров. Результат: таблица
распределения качества и языков (Т3.2) + анонимизированный пример «до/после»
нормализации.

**3.4 Построение эмбеддингов** (`\label{sec:ch3/embed}`)
Листинг Л3.3 (`clustering/embeddings.py`): батчевое построение, кеш `.npz`,
индексная запись в `email_embeddings`. Результат: размерность векторов, число
векторов после фильтра, размер кеша, время построения (плейсхолдеры).

**3.5 Кластеризация и подбор параметров** (`\label{sec:ch3/cluster}`) — блоки
результатов 1 и 2.
Листинг Л3.4 (`clustering/tuner.py`): целевая функция Optuna (DBCV + добавки за
устойчивость кластеров и уверенность принадлежности − штраф за долю шума, при
ограничениях допустимости). Результаты:
- Подбор параметров: рисунок F3.2 (история оптимизации Optuna), таблица Т3.6
  (лучшие `min_cluster_size`/`min_samples`, значение цели, важность параметров).
- Сравнение: таблица Т3.3 (HDBSCAN+тюнер vs дефолтные параметры vs KMeans по
  внутренним метрикам).
- Итоговый запуск: таблица Т3.4 (число кластеров, доля шума, DBCV, силуэт,
  индекс Дэвиса–Боулдина), рисунок F3.1 (2D-проекция кластеров, UMAP, из
  `clustering/visualization.py`), таблица Т3.5 (топ-термины TF-IDF по кластерам
  из `clustering/summaries.py`).

**3.6 Ручная проверка и формирование классов** (`\label{sec:ch3/annot}`)
Листинг Л3.5 (`annotation/import_labels.py`): распространение согласованной метки
на кластер и strict-режим (разногласие представителей → `other`). Результат:
кластеры → классы после консолидации, объём ручного труда (число представителей
vs всего писем), таблица итоговых классов и их размеров (Т3.7).

**3.7 Классификатор: обучение** (`\label{sec:ch3/clf}`) — блок 3, часть 1.
Листинг Л3.6 (`models/text_classifier.py`): собственный словарь + обучаемые
эмбеддинги, mean-pooling, линейная голова (контракт `oid,text,label`).
Результат: accuracy, macro-F1, weighted-F1, покрытие на отложенной выборке;
поклассовые precision/recall/F1 (таблица Т3.8); матрица ошибок (рисунок F3.3).
Источник метрик — `evaluation/metrics.py`, обучение — `training/train.py`,
`training/text_vectorizer.py`.

**3.8 Инференс и порог уверенности τ** (`\label{sec:ch3/infer}`) — блок 3,
часть 2.
Листинг Л3.7 (`inference/predict.py`): решающее правило — низкоуверенные
предсказания (по порогу τ) переводятся в `other`. Результат: развёртка метрик по
τ (покрытие vs точность/macro-F1; доля `other`) — рисунок F3.4 и/или таблица
Т3.9, выбор рабочего τ.

### Свод

**3.9 Выводы по главе** (`\label{sec:ch3/concl}`)
Сводная таблица Т3.10 «достигнуто против критериев успеха»
