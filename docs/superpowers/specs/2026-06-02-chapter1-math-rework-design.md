## Что реально используется (сверено с кодом diplom2.0)

- **Эмбеддинги для кластеризации (φ):** `BAAI/bge-m3` — контекстная многоязычная
  модель уровня предложения (`configs/default.yaml`, `clustering/embeddings.py`).
  Векторы используются с косинусной близостью (UMAP `metric: cosine`; HDBSCAN
  `metric: euclidean` на L2-нормированных векторах монотонно эквивалентен косинусу).
- **TF-IDF:** только для извлечения ключевых терминов кластеров
  (`clustering/summaries.py`, `tfidf_min_df/max_df`).
- **Кластеризация:** UMAP (включён, `n_components=15`, `metric=cosine`) → HDBSCAN
  (`cluster_selection_method=eom`); k-means (`n_clusters=8`) — альтернатива
  (`clustering/pipeline.py`).
- **Подбор параметров HDBSCAN:** Optuna + TPE-сэмплер (`clustering/tuner.py`).
  Целевая функция: `DBCV (validity_index)` + `persistence_weight·mean(cluster_persistence_)`
  + `membership_weight·mean(probabilities_)` − `noise_penalty_weight·max(0, noise_ratio − thr)`
  при ограничениях допустимости (число кластеров ∈ [2,20], доля шума ≤ 0.5,
  медианный размер ≥ 5).
- **Метрики кластеризации:** в коде вычисляется **DBCV**; силуэт и Дэвис–Боулдин
  **не вычисляются** (grep по `src/` — пусто). Значит в главе 1 DBCV + стабильность
  + membership выводятся на первый план, а силуэт/DBI остаются классической ссылкой.
- **Классификатор f_θ (WIP):** `models/text_classifier.py` —
  `nn.Embedding(vocab, 128)` → mean-pooling по непустым позициям → dropout →
  `Linear` → логиты. Инференс (`inference/predict.py`) сейчас берёт `argmax`
  логитов — **softmax/порог τ/`other` ещё не реализованы**. Метрики:
  accuracy, macro-F1, weighted-F1 (`evaluation/metrics.py`).
